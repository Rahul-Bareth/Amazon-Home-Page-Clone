# Amazon Clone

A responsive Amazon homepage clone built using only HTML and CSS. This project was created to practice modern front-end development concepts such as Flexbox, CSS Grid, responsive layouts, hover effects, and website structuring.

## Features

* Amazon-inspired navigation bar
* Search bar and menu panel
* Hero banner section
* Best Sellers product showcase
* Product cards and category sections
* Tech and home shopping sections
* Multi-column footer
* Hover effects and smooth scrolling
* Mobile-responsive design

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

## Learning Outcomes

Through this project, I improved my understanding of:

* Semantic HTML structure
* Responsive web design
* Layout creation with Flexbox and Grid
* Background images and positioning
* Hover animations and transitions
* Building real-world website clones
